# Документация tracker-mcp

`tracker-mcp` — MCP-сервер (stdio или HTTP) и CLI для Yandex Tracker REST API. Краткое описание и быстрый старт — в [README](../README.md).

| Страница | О чём |
| --- | --- |
| [Установка и обновление](install.md) | Установочный скрипт, Homebrew, готовые архивы и `SHA256SUMS`, сборка из исходников, платформы, удаление. |
| [OAuth-приложение и токен](oauth.md) | Собственное приложение Яндекс OAuth, права `tracker:read` и `tracker:write`, приложение на каждого агента, отзыв токена. |
| [Подключение к MCP-клиентам](clients.md) | `connect` для Claude Code и Codex, ручное подключение других клиентов, профили, отключение. |
| [HTTP-режим](http.md) | `serve --http` для машин без системного хранилища и удалённых клиентов: токен в заголовке запроса, Docker, Compose, systemd, подключение агентов, модель угроз. |
| [Справочник CLI](cli.md) | Все команды и флаги: `connect`, `serve`, `auth`; профили и переменные окружения. |
| [MCP-инструменты](tools.md) | Как генерируются инструменты, уровни доступа, наборы, частые задачи, аргументы и ответы, постраничная выдача, `api_search`, `api_request`. |
| [Безопасность](security.md) | Хранение токена и права, вырезание учётных данных из ответов, доступ к локальным файлам, протокол и логи. |
| [Решение проблем](troubleshooting.md) | Homebrew tap, Keychain, Secret Service в Linux, SSH, ошибки `401` и `403`, организация, большие ответы. |
| [Переход с предыдущего сервера](migration.md) | Соответствие старых инструментов `tracker_*` новым, отличия аргументов, проверка на тестовой очереди, переключение и откат. |
| [Разработка](development.md) | Структура крейтов, проверки, пересборка спецификации API. |
